# Чек-лист закрытого теста Google Play

Google требует для нового аккаунта разработчика-физлица: **не менее 12
тестировщиков, непрерывно участвующих в закрытом тесте 14 дней подряд**, и
только после этого открывается доступ к production. Ниже — порядок действий.

## 1. До загрузки сборки

- [ ] Аккаунт Play Console создан и верифицирован (адрес, телефон, документ).
- [ ] Заполнены *App content*: политика конфиденциальности (URL из
      `privacy-policy.md`), Data safety, целевая аудитория (18+ или 13+),
      декларация рекламы — **есть реклама: да**, декларация COVID/финансов — нет.
- [ ] Указано, что приложение содержит рекламу (Play Console → Store presence).
- [ ] Создан AdMob-аккаунт, приложение в нём зарегистрировано, получены
      реальные `app id` и два ad unit id (interstitial и rewarded).
- [ ] Ключ подписи: `keytool -genkey -v -keystore narda-release.jks -keyalg RSA
      -keysize 2048 -validity 10000 -alias narda`, файл положен вне репозитория,
      путь и пароли прописаны в `android/key.properties`.
- [ ] Play App Signing включён (Google хранит ключ, загрузочный — свой).

## 2. Сборка релиза

```bash
cd app
flutter build appbundle --release \
  -Padmob_app_id=ca-app-pub-XXXXXXXXXXXXXXXX~YYYYYYYYYY \
  --dart-define=ADMOB_INTERSTITIAL=ca-app-pub-XXXXXXXXXXXXXXXX/AAAAAAAAAA \
  --dart-define=ADMOB_REWARDED=ca-app-pub-XXXXXXXXXXXXXXXX/BBBBBBBBBB
```

- [ ] AAB собирается без ошибок, лежит в `build/app/outputs/bundle/release/`.
- [ ] `flutter build apk --release` (те же флаги) — размер APK ≤ 50 МБ.
- [ ] На реальном устройстве проверено: реклама показывается **между**
      партиями и ни разу во время партии.
- [ ] Версия в `pubspec.yaml` поднята (`version: X.Y.Z+N`), `versionCode`
      больше предыдущего.

## 3. Материалы листинга

- [ ] Название, краткое и полное описание — узбекский (`listing-uz.md`) и
      русский (`listing-ru.md`); узбекский вычитан носителем.
- [ ] Иконка 512×512 (`icon-512.png`).
- [ ] Feature graphic 1024×500 (`feature-graphic-1024x500.png`).
- [ ] 4–8 скриншотов телефона 1080×1920: меню, партия с ботом, выброс,
      «Qoidalar», статистика, темы.
- [ ] Категория: Games → Board. Теги: настольные, стратегия.
- [ ] Контактный e-mail и (по желанию) сайт.

## 4. Закрытый тест

- [ ] Создан трек *Closed testing*, список тестировщиков — e-mail-адреса
      Google-аккаунтов (**минимум 12**, лучше 15–16 с запасом на выбывших).
- [ ] Каждый тестировщик принял приглашение по opt-in ссылке и **установил**
      приложение (Google считает именно установивших).
- [ ] Дата старта отсчёта 14 дней зафиксирована: ______________
- [ ] Тестировщики не удаляют приложение все 14 дней (напомнить в чате).
- [ ] Раз в несколько дней выкладывается обновление и собирается обратная связь.

## 5. Definition of Done офлайн-релиза (§P3 спеки)

- [ ] Свежая установка → партия с ботом начинается в два тапа.
- [ ] 20 партий подряд человек-против-бота: ни одного крэша и ни одного
      нелегального хода.
- [ ] Property-тесты ядра зелёные:
      `cd packages/narda_core && dart test`.
- [ ] Interstitial не появляется во время партии.
- [ ] AAB собирается.
- [ ] APK ≤ 50 МБ.

## 6. После 14 дней

- [ ] В Play Console появилась кнопка запроса production-доступа — заполнить
      анкету (как тестировали, что меняли по фидбеку).
- [ ] После одобрения — промоушен сборки из closed в production.
